# 小米手环 9 正计时

当前手环端版本：`1.0.4`（`versionCode: 5`）。本版本为小米手环 9 的胶囊形屏幕优化单行大标题项目列表，并移除导致部分设备安装失败的第三方键盘资源。

这是一个双端工程：

- `band-app`：运行在小米手环 9 标准版（192 x 490）的 Vela 快应用。
- `astrobox-plugin-v2`：当前版本 `1.1.0`，API Level 4 手机配置插件，用于 iOS/桌面版 AstroBox 的项目管理和记录查询。
- `astrobox-plugin`：旧版 API Level 1 插件，仅为兼容旧环境保留，不再作为 iPhone 版本使用。

## 已实现功能

- 手环默认提供“工作、阅读、学习、运动、娱乐、个人”六个项目，页面只显示项目标题，不显示分类说明。
- 手环端可删除项目；每次点击“添加自定义”会新增“自定义1、自定义2……”项目。
- 选择项目开始正计时，支持暂停、继续、取消和完成。
- 计时状态即时持久化；息屏或应用被回收后再次打开可继续计时。
- 完成后保存项目、开始时间、结束时间、时长和日期。
- 手环端查看当天记录条数、总时长，并按项目类别排序。
- 手机端查看、新增、改名、修改分类和删除项目，并同步到手环。
- 手机端按日期和类别查看往日记录。
- 蓝牙断开后可重试同步；记录按唯一 ID 去重。

## 构建手环应用

环境要求：Node.js 18+、pnpm 或 npm。

```bash
cd band-app
pnpm install
pnpm run build
```

构建产物位于 `band-app/dist/`。通过 AstroBox 安装 `run.abox.forwardtimer.debug.1.0.4.rpk` 到小米手环 9。已安装旧版本时可以直接覆盖升级。

> `manifest.json` 的 `designWidth` 已设置为 `192`，不要改成手环 9 Pro 使用的 `336`。

## 构建手机配置插件

运行要求：AstroBox `2.2.0` 或更高版本。构建要求：Rust stable，并安装 `wasm32-wasip2` 目标。

```bash
cd astrobox-plugin-v2
rustup target add wasm32-wasip2
python3 scripts/build_dist.py --release --package
```

生成文件位于 `astrobox-plugin-v2/dist/正计时配置.abp`。已验证的发行副本为：

```text
S:\data\personal\mi-band-9-timer\安装包\ForwardTimer-iOS-V4-1.1.0.abp
```

插件使用 API Level 4 和 WASI 3，功能包括：

- 项目列表按“工作、阅读、学习、运动、娱乐、个人”分类显示。
- 调用手机输入对话框新增项目或修改名称，名称最多 12 个字符。
- 修改项目分类、确认删除，以及断线时保存待同步操作。
- 连接小米手环 9 后手动同步项目和删除标记。
- 按日期查询历史记录，并按类别排序显示条数、总时长和完成时间。

### iPhone 安装说明

API Level 4 插件可以在 AstroBox 的 iOS 运行时执行，但 iPhone 版 AstroBox 不一定提供本地 `.abp` 文件导入入口。若从“文件”App 打开时提示“不支持”，不是 ABP 压缩包损坏，也不能通过改扩展名解决。

可行发布流程是把完整项目上传到自己的 GitHub 仓库，再将该仓库提交到 AstroBox 官方插件源，从 AstroBox 插件市场下载安装。根目录 `index.txt` 已指向 `astrobox-plugin-v2/dist`；如果只把 `astrobox-plugin-v2` 单独作为仓库，它内部的 `index.txt` 会指向 `dist`。提交市场前请替换 `manifest.json` 中的作者和网站信息。桌面版可先用同一 ABP 做功能验证。

## 使用流程

1. 在手环端安装或覆盖安装 `run.abox.forwardtimer.debug.1.0.4.rpk`。
2. 从 AstroBox 插件市场/插件源安装“正计时配置”V4 插件；支持本地导入的平台也可直接导入 `ForwardTimer-iOS-V4-1.1.0.abp`。
3. 在 AstroBox 中连接小米手环 9，打开插件并允许设备、互联接收和互联发送权限。
4. 打开插件后点击“立即同步”，先取得手环现有项目和历史记录。
5. 在“项目管理”中添加、改名、改分类或删除项目；在线时会立即发送，离线时会保存在手机，下次点击“立即同步”继续同步。
6. 在“历史记录”中使用“前一天 / 今天 / 后一天”查看往日数据。

手环端日常流程：

1. 打开手环“正计时”，选择项目开始计时。
2. 计时过程中可暂停、继续、取消或完成。
3. 完成后记录立即保存在手环，并尝试发送到手机。
4. 在手环“项目管理”中点击“添加自定义”，可依次创建“自定义1、自定义2……”项目。

## 数据与限制

- 手环保留最近 1000 条记录，手机插件保留最近 5000 条记录。
- 手环没有独立网络能力，同步依赖 AstroBox 与手环的蓝牙连接。
- V4 插件在插件私有目录的 `data/forward_timer_state.json` 中保存项目、删除标记和最近 5000 条记录。
- 手环通信与项目同步协议见 `docs/sync-protocol.md`。
- 正式发布前请替换 `author`、`website`，并按发行要求准备签名证书。
